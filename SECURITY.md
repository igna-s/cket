# Reportar una vulnerabilidad

`|c>` es experimental. Los parsers de IR, la validación de expresiones, los presupuestos de síntesis y la integración con GCC forman parte de su superficie de seguridad. La evidencia de ASan/UBSan y fuzzing se describe en el README; no constituye una auditoría formal.

Como el repositorio es privado, utilizá [el formulario de seguridad dentro del repositorio](https://github.com/igna-s/cket/issues/new?template=security_report.yml), accesible a sus colaboradores. Incluí un programa C o documento QIR mínimo, el comando de reproducción, las versiones utilizadas y el impacto observado. Los ejemplos deben omitir credenciales y datos sensibles.

Solo la versión experimental actual recibe cambios en este repositorio. Todavía no existe una política de soporte de versiones estables ni un plazo garantizado de respuesta.
