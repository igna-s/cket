# `|c>` / cket 0.4.0 — experimental

A new quantum variant of C for GCC-based compilers.

This prerelease records a working prototype with GCC as its frontend, a custom IR, a native
amplitude engine, and OpenQASM 3 export. It does not certify the version 1.0 requirements.

## Capabilities

- Integer and Boolean registers, ownership, borrows, and fixed products.
- Register arithmetic circuits for multiplication, division, remainder, and comparisons, including
  negative operands with proven ranges.
- `find_known` and `search` without exhaustive solution counting.
- Coherent control, parameterized phases, Fourier/inverse Fourier, and explicit CPU control.
- Owned scalar results and independent QIR modules with control and inversion.
- Document and plan caches, defensive budgets, and resource metrics.

## Validation evidence at release

The local reference configuration used GCC 11.4.0:

- 353 tests passed with zero failures, both normally and with ASan/UBSan across the project's
  compiler chain.
- 145 differential compilations across five optimization levels.
- 24 circuits compiled without tables, up to 32 relevant bits.
- 11 QASM circuits imported in Qiskit/Aer; eight compared amplitudes and three compared transcripts
  with intermediate measurement/reset.

These local results preceded publication. The
[first GitHub Actions run](https://github.com/igna-s/cket/actions/runs/38150646854), completed on
October 11, 2026, independently passed all these checks. The release attachments preserve that
historical evidence. The [current workflow](../../.github/workflows/verify.yml) uses C validation
tools and QuEST instead of Python and Qiskit/Aer; see the
[contribution guide](../../CONTRIBUTING.md) for current commands.

## Contract changes and limits

`find(x,p)` promises one solution. For a known count, use `find_known(x,p,M)`; for an unknown count,
including zero, use `search(x,p,attempts)`. A false `search` result means its budget was exhausted,
rather than proving that no solution exists.

Export supports up to 128 physical qubits; simulation supports 24. A 64-bit divider, complete CFG
analysis, a general C function ABI across translation units, and general ahead-of-time compilation
remain pending. Optional small finite paths remain available; `--no-tables` requires structured
synthesis.

## Reproduce

Use Linux or WSL, with plugin headers matching GCC:

```bash
bash scripts/build.sh
bash scripts/test.sh
build/cket examples/find.c --run --seed 7 -o build/demo
```
