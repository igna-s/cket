# Implementación de índices cuánticos

Se añaden lectura, asignación, incremento/decremento y valores de expresión sobre arrays escalares
fijos con índices cuánticos. El selector se acota antes de estrechar su representación, y las
escrituras capturan su valor e índice y retienen los propietarios anteriores. La infraestructura de
programas de valores se extrae de los adaptadores de cadenas para compartirla con el compilador.

Esta entrega registra construcción y compilación de ejemplos. No se ejecutan programas ni suites,
por indicación expresa del usuario. Estados completos, inversas, simulación, sanitizadores,
contextos GCC y consistencia de papers siguen pendientes. Los resultados históricos conservan sus
fuentes. El perfil cotidiano y el bloque 04 permanecen abiertos; la ciberseguridad sigue clásica.

Esta revisión recompila las fuentes tras ajustar su formato y legibilidad. Las dos tentativas
anteriores conservan sus resultados y fuentes por separado.
