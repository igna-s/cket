# Funciones de buffers con índices cuánticos

Se añade indexación coherente sobre punteros prestados, funciones directas encadenadas, alias con
desplazamiento constante y escrituras con historia. El índice se comprueba antes del escalado
canónico de bytes. También se corrige el rechazo de un incremento descartado envuelto en una
conversión entera de GCC.

La construcción y cinco compilaciones de fuentes terminan con código cero. No se ejecuta ningún
ejemplo ni suite, por indicación del usuario. Estados, fases, inversas, recursos, sanitizadores,
contextos GCC y consistencia de papers quedan para el cierre. El perfil cotidiano sigue abierto; la
ciberseguridad permanece clásica. La tentativa anterior conserva sus fuentes y rechazo real.
