# C11 inventory: classical and quantum coverage

This inventory indexes the C11 language, execution environment, standard headers and optional annex
facilities against the current implementation. It retains the
[extended C11 analysis](c11-roadmap.md). The current delivery scope is the
[everyday C core](perfil-c-cotidiano.es.md), agreed on October 23, 2026; closing that profile does
not require implementing every inventory entry. Clause numbers refer to the public
[WG14 N1570 draft](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf). GCC/libc delegation
is not a certification of all classical behavior.

Quantum status: **I** = implemented for the stated cases, **Partial** = some cases implemented,
**P** = pending. Restriction classes are **P** implementation, **R** explicit resources/bounds,
**S** incompatibility in the named context. M0..M9 refer to the roadmap stages. “GCC” and “libc” in
the classical column mean the selected compiler/library retain responsibility for that interface.
Any physically incompatible behavior belongs to a context, not to an entire C construction or
header.

The machine-readable index currently contains 1224 entries: 762 pending, 94 partial and 368
metadata-only. `python3 scripts/inventory_c11.py --require-complete` exits unsuccessfully while
these implementation gaps remain. It checks declared status, not behavioral correctness. The new
[string span/search adapters](c11-string-searches.md) have deferred full qualification; their
partial implementation status does not claim that the pending tests have passed.
`tests/validate_library.c` probes unsupported contexts across 210 function/macro interfaces with
2100 specific quantum diagnostics, after checking each fixture as ordinary C. Existing positive
adapters have their own state, inverse and integration validators. The boundary matrix does not
exercise every index entry or count a rejection as quantum compatibility.

## Operators, assignments and combined expressions

[Versioned scalar assignments](c11-history.md) are partial implementation: unconditional and
[structured coherent updates](c11-control.md) preserve old inputs and live dependents in retained
registers. Derived history has checked inverse cleanup; known basis roots can be restored; unknown
root history remains a joint output until context end.
[Structured CPU scalar joins](c11-cpu-control.md) transport selected owners and actual saved inverse
dependencies. General CFG joins, runtime iterations, general memory overwrites and remaining
expression effects remain P/R. The assignment rows below refer to this bounded contract. Selected
scalar conditional/logical effects now have a [saved-decision contract](c11-lazy-values.md). Mixed
CPU effects, source-level sequencing and general ABI/layouts remain open.

to every family; 7.31's future/reserved names must not be repurposed for undocumented quantum

coverage; adding them cannot close a missing C11 entry.

Optional C11 facilities remain explicit entries. A feature-test macro or an absent libc facility
must not be described as an implemented quantum feature. The extended complete-compatibility roadmap
includes a declared decision and evidence for each, and implementation where that facility is part
of the supported target.

## Evidence and next implementation work

Current evidence is in the native/frontend/QuEST tests and the [language contract](language.md),
[IR verifier contract](ir-verification.md) and [circuit ABI](circuit-abi.md). These tests cover
finite selected programs, operators, states and sampled channels. They do not test all rows above.
The papers describe a historical 0.4.0 evaluation, not completed C11 coverage.

The immediate executable work is M1/M2: fix ordinary C and borrow regressions, add library scalar
adapters with preserved inputs, and track every adapter's tests and unsupported contexts. M7 remains
pending until the family index has individual-interface implementation and integration evidence. No
percentage based only on recognized headers or rejected functions is a completion measure.

The machine-readable [interface index](c11-library.json) enumerates names from N1570 Annex B,
expands target integer/format/atomic families, includes optional Annex K entries, and supplements
the `stdalign.h` summary with normative 7.15. Each row has a quantum status, restriction classes,
milestone, contract and test paths where finite evidence exists. `metadata-only` means a
preprocessing or CPU facility; it is not a quantum implementation. Missing per-interface tests
remain open even when a family has representative tests. This index does not certify all
implementation-defined additional widths or a complete library.
